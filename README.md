# Lights Direction

Lights Direction is a Python project designed to help students identify a lighted path between campus buildings.

## Project Purpose

The goal of this project is to create a simple program that allows a student to enter their information, choose a starting building and destination, and activate the lights associated with those locations.

## Features

- Prompts the student for their name and student ID
- Allows the user to enter a starting and ending location
- Checks whether the entered building names are valid
- Activates the lights for the selected locations
- Provides a message telling the user to follow the lighted path

## Building Codes

The program currently accepts the following building abbreviations:

- `TBE`
- `AEB`
- `SEB`

## How to Run

1. Download or clone the repository.
2. Open the project in a Python environment.
3. Run `copyog.py`.
4. Enter the requested student information.
5. Enter the starting and ending building abbreviations.
6. Follow the prompts shown by the program.
